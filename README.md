# Penguin-Species-Classifier

This project uses KNN Machine learning model to evaluate and predict species of penguins

# Features used 

For training : 'Culmen Length (mm)', 'Culmen Depth (mm)', 'Flipper Length (mm)'
For testing : 'Species'

# Tools used 

Pandas and sklearn

# How to download 

Open up a terminal and write ```pip install pandas```
On the same terminal write ```pip install scikit-learn```

# How to run

```python Penguin.py```  

# Make sure the csv is in same file as .py
